# Security policy

Please do not disclose a suspected vulnerability in a public issue.

Use GitHub's private vulnerability reporting for
`potatohoney-p/weasley-deepmind`. Include affected versions, reproduction steps,
impact, and suggested mitigations. Remove API keys, memory contents, personal
data, and live database credentials from the report.

The maintainers will acknowledge a complete report, investigate it, and publish
a coordinated fix and advisory when appropriate. Supported fixes target the
latest release and the default branch.
